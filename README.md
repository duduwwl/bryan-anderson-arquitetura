# Visare Arquitetura e Interiores

Site institucional da Visare, com Bryan Anderson, Igor Penido e Lucas Sales.

## Conteúdo

- Escritório e equipe
- Portfólio com Alto da Maia, Residência L|I e visualização de área externa
- Galerias ampliáveis e filtros
- Serviços, processo e contato oficial
- Layout responsivo, animação da abertura e suporte a movimento reduzido

## Publicação

GitHub Pages: https://duduwwl.github.io/bryan-anderson-arquitetura/

Site estático em HTML, CSS e JavaScript, sem dependências externas. Atualizações da branch main são publicadas pelo GitHub Pages.

Instagram: https://www.instagram.com/visarearquitetura/

## Imagens

Referências fornecidas pelo proprietário do projeto. Retratos individuais receberam limpeza do texto sobreposto por imagegen. Capturas de projetos são enquadradas com SVG para preservar a arquitetura original e ocultar controles da interface.
